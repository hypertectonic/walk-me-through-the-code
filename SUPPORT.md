# Support

For installation and usage questions, start with the README and its
troubleshooting section. If the problem remains, open a GitHub issue with the
Walk Me Through the Code version, Node.js version, agent host, operating system,
the command that failed, and sanitized output.

For reproducible bugs, open a GitHub issue with the smallest safe reproduction
and the expected and observed behavior. Search existing issues first.

For suspected vulnerabilities, use the private process in `SECURITY.md`. Do not
post security details in a public support or bug issue.
