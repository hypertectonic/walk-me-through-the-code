# Security Policy

Security fixes are considered for the latest published version of Walk Me
Through the Code.

If the repository Security tab offers **Report a vulnerability**, use it. If it
does not, open a GitHub issue containing only a request for private security
contact. Do not include vulnerability details, secrets, or source code. A
maintainer will arrange a private channel for the report.

The Viewer binds to `127.0.0.1` by default. `--share private` deliberately
exposes it only to a trusted LAN or Tailnet and must be enabled explicitly. The
project does not provide a hosted service or public sharing. Agent hosts remain
separate trust boundaries with their own permissions and data-handling rules.
