# Code of Conduct

We want participation in Walk Me Through the Code to be respectful, safe, and
useful.

Be considerate, assume good intent, discuss ideas rather than people, and give
specific constructive feedback. Harassment, discrimination, threats, unwanted
sexual attention, deliberate intimidation, and publishing another person's
private information are not acceptable.

Maintainers may edit or remove comments, close conversations, or restrict
participation when conduct harms the community. Decisions should be
proportionate, consistent, and focused on restoring a productive space.

If GitHub offers a private reporting tool for this repository, use it for
conduct concerns. Otherwise, open an issue containing only a request for
private contact. Do not include incident or personal details. A maintainer will
arrange private follow-up.
